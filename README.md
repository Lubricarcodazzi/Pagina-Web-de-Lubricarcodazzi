# Lubricar Codazzi

Landing de Lubricar Codazzi, comercio de lubricantes, filtros, baterías y accesorios para vehículos en Agustín Codazzi, Cesar. El sitio usa React, TypeScript y Vite.

## Requisitos

- Node.js 24 o una versión compatible con Vite 8.
- npm.

## Ejecutar localmente

```sh
npm ci
npm run dev
```

Vite muestra la dirección local en la terminal (por defecto, `http://localhost:3000/`).

## Comprobaciones

```sh
npm run lint
npm run build
npm run preview
```

La carpeta `Docs/` contiene materiales originales del negocio y se mantiene fuera de Git. No copies allí archivos que deban publicarse en el sitio; selecciona y copia cada activo aprobado al código web.
